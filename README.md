# 🍌 Banan Launcher

**Banan Launcher** to nowoczesny launcher Minecrafta z ciemnym interfejsem, bananowymi akcentami i prostą obsługą. Został zaprojektowany tak, aby uruchamianie gry, zarządzanie wersjami i modami było wygodne i intuicyjne.

### ✨ Funkcje
- 🍌 Nowoczesny, ciemny interfejs z animacjami.
- 🎮 Uruchamianie Minecrafta.
- 📦 Wybór wersji gry.
- 🧩 Przeglądanie i zarządzanie modami.
- ☕ Pobieranie środowiska Java.
- 👤 Ustawianie nicku gracza.
- ⚙️ Konfiguracja launchera.
- 💾 Zapisywanie ustawień.
- 🖥️ Wersja EXE dla systemu Windows.

### 🚀 Uruchamianie
1. Pobierz najnowszą wersję EXE z zakładki **Releases**.
2. Uruchom pobrany plik.
3. Skonfiguruj launcher.
4. Wybierz wersję Minecrafta i rozpocznij grę!

### 💛 O projekcie
Banan Launcher to projekt tworzony z pasji do Minecrafta. Jego celem jest połączenie prostoty, funkcjonalności i wyjątkowego bananowego stylu.
